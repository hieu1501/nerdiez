# Agent Instructions

## Tech Stack
- Frontend: React Native, TypeScript (Strict)

## Frontend requirements
- Mobile app for posting articles like Reddit with learning functions like Duolingo and some other functions like memorizing, lesson reviews.
- Dark theme, simple, user-friendly UI/UX, easy-looking fonts.
- Separate controllers to handle communication with server easily.
- Explore tab for sharing lessons and information, UI/UX designed like Reddit.
- Learn tab for lessons and quizzes, designed like Duolingo.
- Profile tab.
